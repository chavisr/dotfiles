# Environment

- **Workstation** — Artix Linux using dinit (not systemd) with niri.
- **sudo** — Use `sudo -A <cmd>`.
- **Python** — Use the project venv if it exists; otherwise ask whether to create one or use the shared `/home/chavi/.venv/bin/{python,pip}`.
- **Search** — Use `rg` instead of `grep`.
- **File deletion** — Use `trash-put` instead of `rm`.
- **Images** — Use `imv` to show images; it updates automatically, so there is no need to reopen them.
