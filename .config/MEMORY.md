# Environment

- **Workstation** — Artix Linux using dinit (not systemd).
- **Python** — Use the project venv if it exists; otherwise ask whether to create one or use the shared `/home/chavi/.venv/bin/{python,pip}`.

- **sudo** — Use `sudo -A <cmd>`.
- **File deletion** — Use `trashy` instead of `rm`.
